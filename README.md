# 23魔方原始数据 → 全 rsid 转码工具

版本：**v1.2.0**

板块一上传原始数据，板块二载入参考模板（编号 / 坐标对照表）；模板在浏览器本地解析，把可解码位点转为标准 rs 号，解码不到的保留原编号并列入未解码清单。**所有解析与解码都在本机浏览器内完成，文件不上传、不经过服务器。** 坐标基准 hg19 / GRCh37。

## 目录结构

```
23-rsid-/
├── index.html                    # 应用入口（HTML + CSS + JS；对照表不内联，体积小）
├── mofang_template-v1.2.0.txt.gz # 内置模板（板块二按钮同源下载，也可手动上传）
├── .nojekyll                     # 禁止 Jekyll 处理，保证静态资源原样发布
├── README.md
└── 补充对照表/                   # 方案①：111-1975-1172 未解码清单 b151 坐标反查分组结果
    ├── 补充对照表_唯一rs.tsv      # 坐标唯一对应 rs，已并入模板坐标兜底表
    ├── 补充对照表_多rs歧义.tsv    # 同坐标多 rs，候选 rs/alt 同序，需按基因型/ref-alt 仲裁
    ├── 补充对照表_未命中.tsv      # b151 无收录，需更新版 dbSNP 或厂家探针表
    └── 统计说明.txt
```

## 使用流程

1. **板块一 · 上传原始数据**：23魔方 / 23andMe 等四列 / 五列 txt、csv、tsv；注释行与表头自动跳过。
2. **板块二 · 载入参考模板**：
   - 点「从仓库下载内置模板」按钮，自动拉取同仓库的 `mofang_template-v1.2.0.txt.gz` 并解析；
   - 离线、内网或使用自定义对照表时，改为直接在板块二上传模板文件（`.txt/.tsv/.csv/.gz`，可多选）。
   - 模板可先于或后于数据载入；后补模板会对已上传样本自动重算。
3. 结果区下载转码结果（全 rsid txt）与未解码清单。

## 支持的模板格式

- **精简分段格式**：`# probe` 段为「编号 rs」直查表，`# pos` 段为「chr:pos rs」坐标兜底表；
- **4 列解码表**：`a编号 标准号 染色体 位置`；
- **3 列坐标字典**：`编号/rs 染色体 位置`（首列为 rs 才入坐标表）；
- **两列**：`编号 rs` 直查表。

## 解码口径

- **编号直查**：a 编号、kgp 探针号先在模板直查表转标准 rs 号。
- **坐标兜底**：编号未命中且行内带染色体 / 位置时，按 `chr:pos` 在模板坐标字典反查 rs。
- **保留原样**：已是 rs 的位点直接保留；模板无映射的 mf / Affx 等探针号保留原号并计入未解码清单。
- **X / Y / MT 忽略**：性染色体与线粒体位点自动跳过，不参与解码、不计入未解码清单、不写入结果文件。
- 缺失 / 模糊基因型（--、NN 等）原样保留，不剔除位点。

## 本地预览

直接用浏览器打开 `index.html` 即可；本地 `file://` 打开时仓库下载按钮取不到模板属正常现象，请用板块二手动上传 `mofang_template-v1.2.0.txt.gz`。如需本地静态服务器：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

## 上架 GitHub Pages

仓库：`https://github.com/Mothdna/23-rsid-`（分支 `main`）。

1. 把 zip 内顶层目录 `23-rsid-/` 里的 `index.html`、`mofang_template-v1.2.0.txt.gz`、`.nojekyll`、`README.md` 及 `补充对照表/` 上传到仓库**根目录**（不要多套一层 `23-rsid-/` 文件夹）。
2. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，保存。
3. 等待 1–10 分钟，访问 `https://Mothdna.github.io/23-rsid-/`。

> 模板文件必须与 `index.html` 同处仓库根目录，页面按钮的相对路径下载才能命中；跨域兜底地址为 `https://raw.githubusercontent.com/Mothdna/23-rsid-/main/mofang_template-v1.2.0.txt.gz`。
