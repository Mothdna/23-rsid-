# 23魔方原始数据 → 全 rsid 转码工具

版本：**v1.1.0**

上传 23魔方导出的原始 txt（a 编号 / kgp / mf 等非 rs 位点），内置对照表把可解码位点转为标准 rs 号；解码不到的位点保留原编号并列入未解码清单。**所有解析与解码都在本机浏览器内完成，文件不上传、不经过服务器。** 单文件自包含，对照表已内联，无外部资源依赖。坐标基准 hg19 / GRCh37。

## 目录结构

```
mofang-to-rsid/
├── index.html              # 单文件应用入口（HTML + CSS + JS + 对照表全部内联）
├── .nojekyll               # 禁止 Jekyll 处理，保证静态资源原样发布
├── README.md
└── 补充对照表/             # 方案①：111-1975-1172 未解码清单 b151 坐标反查分组结果
    ├── 补充对照表_唯一rs.tsv      # 坐标唯一对应 rs，已并入内置坐标兜底表
    ├── 补充对照表_多rs歧义.tsv    # 同坐标多 rs，候选 rs/alt 同序，需按基因型/ref-alt 仲裁
    ├── 补充对照表_未命中.tsv      # b151 无收录，需更新版 dbSNP 或厂家探针表
    └── 统计说明.txt
```

## 解码口径

- **编号直查**：a 编号、kgp 探针号先在内置对照表中直查标准 rs 号。
- **坐标兜底**：编号未命中且行内带染色体 / 位置时，按 `chr:pos` 在内置坐标字典中反查 rs。
- **保留原样**：已是 rs 的位点直接保留；本地对照表无映射的 mf / Affx 等探针号保留原号并计入未解码清单。
- **X / Y / MT 忽略**：性染色体与线粒体位点自动跳过，不参与解码、不计入未解码清单、不写入结果文件。
- 缺失 / 模糊基因型（--、NN 等）原样保留，不剔除位点。

## 本地预览

直接用浏览器打开 `index.html` 即可；如需本地静态服务器：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

## 上架 GitHub Pages

1. 在 GitHub 新建一个**公开**仓库（私有仓库需要 Pro 套餐才能用 Pages），例如 `mofang-to-rsid`。
2. 把 `index.html`、`.nojekyll`、`README.md` 及 `补充对照表/` 上传到仓库根目录，分支用 `main`。
3. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，保存。
4. 等待 1–10 分钟，访问 `https://<你的用户名>.github.io/mofang-to-rsid/`。

## 本版本变更（v1.1.0）

- 修复文件选择需点两次才能载入的问题：上传区由 `label` 改为 `div`，消除原生触发与脚本 click 的叠加；选择后清空 input，允许再次选择同一文件；对照表预载 promise 复用，避免首次点添加时重复解压。
- X、Y 染色体与线粒体 MT 位点自动忽略，不再计入无法解析行。
- 常染色体 `.` 占位编号行保留坐标走兜底，不再判为坏行。
- 新增方案①补充对照表：未解码清单按 b151 全坐标表反查，分唯一 rs / 多 rs 歧义 / 未命中三组。
